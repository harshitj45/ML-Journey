## Mini Project — Student Record System

### Description
Menu-driven CLI app to manage student and teacher
records with file save/load functionality.

### Concepts Used
- Abstract class (ABC, @abstractmethod)
- Inheritance + super()
- @property with validation
- Custom exceptions
- File I/O with open()
- try/except/finally
- Dunder methods

- `day14_p38_file_manager.py` — File save/load logic
- `day14_p39_complete_system.py` — Complete menu-driven app
